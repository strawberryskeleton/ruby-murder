# Ruby Murder 🐦‍⬛
![logo](./assets/logo.png)

scroll scroll to get ruby, but you are a crow.

**Objective of the Game**: collect as many shiny rubies as you can before the timer runs out

**Controls**: scroll using your mouse wheel / from trackpad / from scroll knob (whichever way you scroll on your device noramlly)

## Features
- custom logo
- start and end/restart screen
- moving slider, without moving webpage
- randomly spawning targets
- collision detection
- timer + score calculation

## Tech Stack
- HTML
- CSS
- Vanilla JS
